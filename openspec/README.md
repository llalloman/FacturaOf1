# OF1 Spec-Driven Development

`openspec/` is the source of truth for product boundaries, behavior, API contracts,
ownership rules, and acceptance scenarios across OF1 Solutions.

## Workflow

1. Inspect the current behavior and evidence.
2. Create or update a change under `changes/active/`.
3. Review `proposal.md`, `design.md`, requirements, and tasks.
4. Implement only the approved tasks.
5. Verify code, API, permissions, data ownership, and user flows.
6. Update permanent specs and archive the completed change.

Existing automation specifications under `automation/openspec/` remain valid until
they are migrated into this root catalog.
